## What is this

This repository is the official Homebrew tap for [AgentSend](https://github.com/RayMorTwinkle/agentsend) — an agent-first file transfer tool with LAN transfer, P2P relay and an async mailbox. The cask definitions are generated and updated automatically by [GoReleaser](https://goreleaser.com) on every release.

Homepage: <https://agentsend.raymor.top>

## 🚀 Install

```bash
brew tap RayMorTwinkle/tap
brew install --cask agentsend
```

Upgrade & uninstall:

```bash
brew upgrade --cask agentsend     # upgrade to the latest release
brew uninstall --cask agentsend   # uninstall
brew untap RayMorTwinkle/tap      # remove this tap
```
